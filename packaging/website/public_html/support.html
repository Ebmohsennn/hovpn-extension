Everything you need to get Hovpn running.

Installing Hovpn

Add the extension

Add Hovpn to your browser from the Chrome Web Store. It works in Chrome, Edge, Brave and Chromium.

Add to Chrome

Install the helper

Download the helper for your system and run it once — it bundles everything, no admin needed.

macOS Windows

Restart your browser

Fully quit and reopen your browser so it detects the helper.

Connect

Click the Hovpn icon, add a server (paste a config link) or a subscription URL, and press the big button.

Why do I need the helper?

For security, web browsers can't run a proxy engine on their own. The Hovpn helper is a tiny local app that runs the actual connection on your computer; the extension is just the interface that controls it. It installs only into your own user folder — no admin, and you can remove it anytime.

Frequently asked questions

Does Hovpn provide servers?

No. Hovpn is the software you use to connect to your own server or subscription. You bring the config link or subscription URL from your provider.

Does it slow down my whole computer?

No. Only your browser's traffic is routed through the proxy. Everything else on your computer connects normally.

Is my data collected?

No. There is no account, no analytics, and no telemetry. Your server list and settings are stored only on your device. See the Privacy Policy.

macOS says the helper "can't be opened"

Make sure you downloaded it from hovpn.vip and open it by double-clicking. If macOS still blocks it, right-click the installer and choose Open, then confirm.

Windows SmartScreen shows a warning

Click More info → Run anyway. The installer is safe; this warning appears for new apps until they build reputation.

The extension says the helper isn't installed

Install the helper for your system (above), then fully quit and reopen your browser. If you removed and re-added the extension, its ID may have changed — reinstall the helper.

It won't connect

Check that your config link or subscription is valid and current, try a different server, and confirm your provider's server is online. Latency shown as "timeout" means that server isn't reachable right now.
